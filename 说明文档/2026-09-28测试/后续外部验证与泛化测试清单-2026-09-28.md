## 2. 测试 A：外部工程数据校核（投稿前优先增强项）

### 2.1 目的

现有的 Java—Python 一致性证明两套软件在当前保存快照字段上的计算一致，但不等同于实测、生产定型或制造数据验证。本测试用于补充“精算器工程解释性”的外部证据；它不用于重新比较 GA 策略优劣。

### 2.2 样本选择

至少选取 3 条存在可追溯工程结果的三相方案。优先按下列覆盖组合选取；若某类没有真实记录，应在报告中写明缺失原因，不要用模拟数据代替。

| 优先样本 | 需要覆盖的结构 | 必需来源 |
| --- | --- | --- |
| A1 | 波纹油箱方案 | 已保存 Java 方案、对应目录记录与工程/制造结果 |
| A2 | 散热器油箱方案 | 已保存 Java 方案、对应目录记录与工程/制造结果 |
| A3 | 与 A1/A2 不同的接线组别、铁芯形状或导线类别组合 | 同上；优先非 Dy 或椭圆铁芯分支 |

这里的“工程/制造结果”可以是已审批设计计算书、BOM/成本清单、出厂试验或型式试验记录；必须在报告中注明实际来源及其日期。没有实测记录时，可以只做“设计归档对照”，但不得在论文中称为实测验证。

### 2.3 每条样本的执行步骤

1. 冻结并保存输入：方案 ID、配置 ID、目录记录 ID、价格版本、Java 计算快照、Python/代码版本和执行日期。
2. 通过既定 MCP 后端接口获取 Java 最新计算快照；再以同一完整记录在 Python 单设备精算器重算。
3. 将 Java 与 Python 的 32 个可比字段逐项对照，保留绝对差、相对差和通过判定。
4. 若有外部工程数据，单独将 Java/Python 计算值分别与工程/制造/实测值比较；不得把“Java 与 Python 一致”误写为“与实测一致”。
5. 任一 Java—Python 不一致先定位输入快照、目录映射或公式分支；修复后应重跑受影响样本。外部实测差异则记录数据来源、测试工况和可能差异来源，不直接据此改 GA 算子。

### 2.4 报告必须包含的内容

- 样本编号、配置 ID、方案记录 ID、容量、接线组别、铁芯形状、油箱类型、导线类别；
- 三类证据的来源标识：Java 快照、Python 重算、外部工程/制造/实测；
- 32 个 Java—Python 可比字段的通过数、失败数、最大绝对差/相对差及失败字段列表；
- 对于外部数据，分别列出 P0、Pk、Uk、绕组尺寸、油重、油箱重量、总成本和温升等实际可获得字段，并说明单位、工况和缺失字段；
- 每条样本的结论：仅软件一致、设计归档吻合、具备实测对照，或不具备外部证据；
- 原始接口响应、输入快照和对照 CSV 的归档路径。

### 2.5 论文更新规则

- 若仅完成 Java—Python 对照：维持论文“内部一致性门控”表述，不增加“实测验证”结论。
- 若至少 3 条样本有可追溯外部工程/制造数据：在附录 A 后增加一张“工程/制造对照表”，并在 5.3 中把“尚缺外部验证”调整为实际覆盖范围。
- 若发现 Java—Python 任一关键字段不一致：先修复精算器及其回归数据，再重新生成所有受影响的 GA 论文统计；不能只修改表格文字。

## 3. 测试 B：未覆盖产品分支的 BGA–MGA 泛化验证（扩展结论项）

### 3.1 目的

五个主配置均为 Dy，且仅覆盖圆形/长圆铁芯和波纹/散热器油箱。该测试用于判断论文结论能否谨慎扩展到更多工程分支，并不要求推翻或重跑现有五场景主比较。

### 3.2 最小样本集

从现有可用配置中选择 2～3 个新配置，优先覆盖以下缺口：

1. 至少 1 个非 Dy 接线组别；
2. 至少 1 个椭圆铁芯；
3. 如可取得，再补 1 个与现有类别不同的高低压导线组合或油道候选数大于 1 的配置。

如果没有满足条件的真实配置，不得自行造数据；报告中记录“当前数据库无可用样本”，并维持论文现有外推边界。

### 3.3 运行协议

- BGA 与 MGA 使用相同配置快照、目录/价格快照、第 0 代构造规则和同一批 30 个随机种子；
- 每个配置的第 0 代后真实精算总预算上限 B′，按其搜索域规模预先确定并冻结；记录 N0、工作种群规模 N、B′ 和实际调用数；
- 禁止根据中途结果调高某一方法的预算，缓存命中不计入真实精算调用；
- 若两种方法均为 0/30 严格成功，应作为边界结果保留，报告主导失败原因，不把它误判为算法“通过”或“失败”。

### 3.4 统计与判定

每个新配置报告：

- 严格成功数/30、BGA-only/MGA-only 成功数、McNemar 原始 p 值；
- 对同一配置内的新增主比较统一作 Holm 校正；不得把新配置与旧五场景混在一起后仍沿用旧的校正值；
- 双方共同严格成功样本数；样本数不少于 6 时报告 Hodges–Lehmann 成本变化率、95% CI、Wilcoxon p 值和 Holm 校正值；否则仅作描述；
- 第 0 代后真实精算调用中位数、缓存命中和终止原因；
- 严格档案/近可行档案的最终规模及主导失败约束。

结果只可写成“新增配置下的观察”；只有覆盖范围与样本数量足够时，才调整论文摘要和结论的适用范围。
