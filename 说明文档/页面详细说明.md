# 三相优化实验页面详细说明

本文只说明当前 `experiment_ui/app.py` 已实际渲染的页面、控件和操作结果，依据代码核对日期为 2026-09-22。它不是 GA 原理文档：候选域、初始种群、双档案、交叉和变异规则见[三相GA详细说明-V1-从初始种群到定向变异.md](三相GA详细说明-V1-从初始种群到定向变异.md)；计算分层和验证边界见[实验架构说明-V2.md](实验架构说明-V2.md)。

## 1. 页面是什么，页面不是什么

这是一个本地 Streamlit 研究操作台，用来：读取一条三相产品配置和目录数据；复算单个候选；对比 Java 已保存结果；启动一套默认 GA；以及回放本地轨迹。它不是 Java 业务配置编辑页，页面上的选择不会写回业务数据库。

启动命令：

```powershell
& C:\ProgramData\anaconda3\envs\python310\python.exe -m streamlit run experiment_ui/app.py
```

数据库连接来自 `config/database.local.yml`。业务数据库只读；候选、精算结果和优化过程只写入本地 `outputs/*.sqlite3`。页面首次读取后会缓存配置、历史方案和目录；左侧的“重新连接并刷新”会清除这些数据缓存再读取。

若本机数据库不可用，页面会进入离线轨迹回放状态：只有“轨迹回放”仍可使用，单设备精算、一致性验证和 GA 运行都会提示当前不可执行。

## 2. 实际导航与页面之间的关系

页面不是旧版的“A 区 / B 区 / C 区”三段式布局。实际结构是两级导航：

1. 左侧“实验工作区”选择一级模块：`单设备精算`、`一致性验证`、`GA 优化实验`、`轨迹回放`、`研究说明`。
2. 进入一级模块后，内容区顶部用页签切换该模块内的步骤或视图。

左侧还显示当前选中的三相配置 ID、容量、接线组别、高低压额定值、基础目录加载数量、当前配置历史记录数量和本地轨迹数量。这里显示的是“当前配置历史记录”，不等同于每一条都已经成功还原为当前搜索域内的 GA 种子；真正可还原性会在构造第 0 代时逐条检查。

页面上方的“刷新读取”只刷新数据库缓存；它不删除本地轨迹，也不会修改 Java 配置。

## 3. 单设备精算

一级模块标题为“单设备精算”，实际有三个页签：

```text
1 · 设置本次搜索范围
2 · 选择方案并复算
3 · 查看计算结果
```

### 3.1 设置本次搜索范围

此页签先显示固定产品条件，并通过展开区展示：

- 产品基本需求、性能标准和部分严格约束；
- 完整的产品需求、优化范围与约束字段；
- 铁芯、低压绕组、高压绕组、绝缘、油箱和材料单价等固定计算参数；
- 原始配置 JSON，供核对 Java 入参。

固定条件不会被页面上的 GA 修改。页面可选择的研究边界只有下列结构项：

| 页面控件 | 实际作用 |
| --- | --- |
| 允许搜索的硅钢片牌号 | 多选真实牌号；用于随后单设备候选和 GA 域。 |
| 允许搜索的三相铁芯形状 | 多选圆形、长圆、椭圆；铁芯记录仍受 Java 配置中的直径上下限过滤。 |
| 允许搜索的低压导线类别 | 可多选；下方显示每一类别的目录数以及扁线宽、厚、宽厚比筛选后的记录数。 |
| 允许搜索的高压导线类别 | 同上。每条候选保存“类别 + 完整目录记录 ID”，不拆分宽、厚。 |
| 允许搜索的油箱冷却形式 | 可同时选择波纹油箱、散热器油箱；一个候选只能选其中一种。 |
| 允许搜索的散热片片宽、散热器组数 | 仅选择了散热器油箱时生效。组数可以按 Java 已保存的范围预填，也可由操作者输入逗号分隔的离散值。 |
| 允许搜索的波纹长轴/短轴面数 | 仅选择了波纹油箱时生效；Java 当前配置只保存一个值而不是候选范围，因此页面要求操作者明确输入离散值。 |

这些边界保存到当前 Streamlit 会话中；切换到 GA 页面后仍使用同一份边界。切换三相配置时，旧边界会失效，必须重新设置。

材料单价优先使用当前方案配置中的 `craft_unit_price`。某项为 `null` 或空字符串时，页面才通过本地 Faladi MCP 的只读价格工具补齐到本次 Python 内存；数值 `0` 视为明确配置值，不会被覆盖。两处均缺失时页面会提示该成本不能作为有效比较依据。

### 3.2 选择方案并复算

此页签没有“从目录第一档开始”的入口。操作者必须先从下拉框选择一条可还原的 Java 历史方案；页面用该记录还原候选结构后，才显示编辑表单。若所选历史方案的导线、铁芯、硅钢或冷却型号不在前一页已选研究边界内，页面会提示并拒绝悄悄替换成别的目录记录。

编辑表单实际按四列展示：

| 列 | 可编辑项 |
| --- | --- |
| 铁芯模块 | 硅钢牌号、三相铁芯形状、铁芯目录规格、低压匝数；选择长圆铁芯时额外显示直线段 C 值。 |
| 低压绕组模块 | 低压导线类别与完整线规记录、低压层数、低压油道方案。 |
| 高压绕组模块 | 高压导线类别与完整线规记录、高压层数、高压油道方案。 |
| 冷却模块 | 油箱及完整冷却型号。波纹候选携带波纹记录和长短轴面数；散热器候选携带片宽、中心距、片数、组数和关联目录记录。 |

单设备页的匝数、层数输入框允许填写指定整数，目的是复现和排查一条指定结构；它不等于 GA 的合法域。GA 中低压匝数取 Java 页面 `optimizationScope.lowVoltageTurnsMin/Max`，高压层数取 `craft_high_coil.minLayerCount/maxLayerCount`；低压层数则按所选导线类别合法化：箔材等于低压匝数，扁线只能为 2 或 4。

点击“运行单设备精算并给出约束诊断”后，结果会保存到当前会话。随后应切换第三个页签查看，而不是期待同页自动展开结果。

### 3.3 查看计算结果

尚未运行时，此页只提示先选一条可还原的 Java 历史方案。运行成功后显示：

- 空载损耗 P0、负载损耗 PK、短路阻抗 UK、总成本；
- 油顶温升、低压温升、高压温升、总装配重量；
- 本次实际冷却型号及其来源；
- 有超限时的中文约束诊断表；
- 可展开的完整精算指标表。

约束诊断不会只给英文编码。每一项会显示中文名称、规则说明、允许下限、允许上限、实际值、超出量和归一化超限。规则本身只有单侧边界时，会明确显示“无上限”或“无下限”，而不是伪造一个区间。

页面结果状态只有三层含义：

- `未能完成精算`：几何、目录或公式输入导致计算未完成；
- `严格合格`：当前 Python 已建模约束均未超限；
- `可计算，但有若干项约束未满足`：即“近可行 / 不合格”，可用于 GA 搜索方向，不能作为最终设计。

## 4. 一致性验证

此模块有两个页签：`字段对比` 和 `对比口径说明`。

“字段对比”中选择一条当前配置的 Java 历史方案，点击“执行字段对比”后，页面会：还原该记录的候选；调用 Python 精算器；并逐项显示 Java 保存值、Python 重算值和一致/不一致结论。

基础对比字段包括磁密、硅钢单位损耗、低高压绕组高度、低高压轭距、P0、PK、UK 和总成本。记录保存了 `calculationSnapshotVersion=1` 时，还会比较温升、油重、油箱及散热部件重量、导线/硅钢重量和成本分项；旧记录未保存快照时，这些项目明确标为未验证。

这个页面**不会自动请求 Java 后端重新计算**。正确联调顺序是：先通过 `faladi_mcp` 按后端约定触发同一保存方案的最新计算并取得最新记录/快照；再在本页比较。否则这里比较的是 Java 的旧保存值与 Python 当前重算值，不能称为实时一致性结论。

## 5. GA 优化实验

GA 页只有在当前会话已在“设置本次搜索范围”中保留至少一种硅钢、铁芯形状、低压导线类别、高压导线类别和冷却形式时才可进入。否则页面只显示提示，不会自行猜测搜索域。

进入后先显示四项运行概况：当前配置历史记录数、搜索模块数（4 个）、允许冷却形式和实验记录位置。其后的“了解本次 GA 如何搜索”为折叠说明。实际操作分为两个页签：

```text
第 0 代准备
遗传迭代
```

### 5.1 第 0 代准备

该页的可输入参数只有：

- 历史种子比例；
- 随机种子。

展开“查看第 0 代覆盖计划与候选范围”后，可查看 A 单项覆盖、B 关键两两覆盖、整数来源和长圆 C 值规则。点击“生成第 0 代并写入本地轨迹”后，页面构造并精算：多背景 A/B 覆盖候选、同配置或相似配置的可还原历史候选、以及随机完整合法候选；它们会去重后写入一份独立的 `initial-preview-*.sqlite3` 轨迹。

运行时页面显示第 0 代实时进度：已处理候选、实际精算调用、缓存命中和并行精算线程数。完成后显示历史种子数、覆盖候选数、随机补充候选数、自动目标规模、候选来源分布、结果分布、不可计算原因，以及严格合格/近可行候选各前五名。

第 0 代预览没有执行父代选择、交叉、变异、代际迭代或双档案更新。因此此处的“严格合格候选前五名”和“近可行候选前五名”只是本批候选的评价排序，不是完整 GA 的最终档案。

若配置内容、目录、研究边界、候选集合和精算公式版本均未变化，随后在同一页面会话启动 GA 时，程序可以复用本页的第 0 代精算缓存；GA 仍会将这些候选记入自己的轨迹，只是不重复调用精算器。

### 5.2 遗传迭代

此页将参数分到三个页签，而不是全部放在一页：

| 页签 | 当前可设置参数 |
| --- | --- |
| 运行规模 | 本次实验策略、最大代数、随机种子、历史种子比例，以及本次搜索范围与第 0 代覆盖计划。 |
| 交叉与变异 | 参数块交叉率、结构电磁耦合交叉占比、总变异率、诊断反馈变异占比、每次诊断的局部精算数。 |
| 档案与细化 | 每类档案保留数、每代精英保留数、每代有效域随机注入比例、严格精英邻域精算上限。 |

“本次实验策略”可选当前页面参数、消融基线、仅耦合交叉、耦合交叉加经验有效域注入、完整诊断反馈策略。选择预设后，其交叉、注入和定向变异开关以预设为准，页面其它滑条不会偷偷覆盖预设；它和 `ga-run --experiment-strategy`、`ga-ablation` 的名称及实际 settings 完全一致。

提交“运行改进 GA，并保存全部实验轨迹”后，程序先评价完整第 0 代，再自动筛选后续遗传使用的工作种群；不可计算或结果不完整的第 0 代、随机注入候选和交叉/变异子代都会保留在轨迹并显示失败诊断，但不会占用后续工作种群槽位或成为父代。若原始第 0 代不足两条可计算完整候选，页面状态会显示“第 0 代恢复采样”，系统在原页面允许域内补抽未见完整组合；找到两个起点后继续，达到自动上限仍不足时会以“无可计算起点”正常停止并保留轨迹。页面在第 0 代完成时显示实际工作种群数；轨迹第 0 代说明同时写入“全量覆盖数、恢复采样数、可计算完整数、工作种群数”。第 0 代没有被选入工作种群的其它候选同样保留在轨迹中。运行期间页面显示当前代、实际精算调用、缓存命中、严格档案和近可行档案数量，以及两类档案的当前前五名。结束时除精算调用、缓存命中和档案数量外，还显示本次耗时。页面切换或普通控件重绘后，可恢复本次会话保存的最近运行状态快照。

结束后页面显示完成代数、是否因停滞提前结束、调用数、缓存命中和档案数量；若有严格合格候选，展示最低成本严格方案；否则展示总超限最小的近可行候选，并明确其不能作为最终设计。两类最终档案表随后显示。

页面不提供任意勾选式“自定义消融”或预算 B / B′ 输入：普通运行按最大代数或停滞停止。页面中的策略下拉只用于单次策略复核；同配置、同搜索域、同批随机种子的成组消融仍必须通过 `main.py ga-ablation` 执行，并固定 B 或 B′。

## 6. 轨迹回放

轨迹回放不依赖业务数据库，不重新精算，也不写回任何数据。进入页面只列出本地 `outputs/*.sqlite3` 的文件名、修改时间和大小；选中文件后必须点击“加载选定轨迹”。这一步只读取运行信息、来源汇总、代际摘要和档案摘要，不会自动解析大文件中所有候选 JSON。

加载后页面会先判断文件类型。

### 6.1 第 0 代预览轨迹

初始预览轨迹提供三个视图：

- `第 0 代概览`：候选生成方式、当前最优结果和说明；
- `候选与精算结果`：按严格合格优先、成本/总超限排序的前 300 条候选；
- `本次预览设置`：搜索域和初始化参数。

它不会显示父代、交叉、变异、代际曲线或双档案，因为这些操作在第 0 代预览中尚未发生。

### 6.2 完整 GA 轨迹

完整 GA 轨迹提供四个视图：

- `运行概览`：来源组成、当前最优结果、最终双档案；
- `代际过程`：每代的中文摘要和数值统计；
- `候选与演化关系`：候选分页表、单条候选的结构、父代、生成方式、本代去向、档案归属、档案处理结果、入档前最后动作以及约束诊断；
- `实验设置`：搜索域、算法参数、实际生效策略、公式版本、核心代码指纹、运行入口与耗时。

进入“候选与精算结果”或“候选与演化关系”时才解析候选级的大 JSON。完整候选表按页显示，每页 200 条，防止大轨迹一次传入浏览器造成长时间白屏。

“本代去向”和“档案归属”含义不同：前者表示候选是否进入下一代工作种群；后者表示它是否被严格档案或近可行档案保留。“入档前最后动作”只记录入档前最后一条创建记录，不可据此推断某个算子对严格解的因果贡献；精英复制和缓存命中会显示为没有新的创建算子。

## 7. 研究说明

此模块有两个页签：`实验流程` 和 `数据与验证边界`。

“实验流程”展示“定义离散设计域—单设备精确评价—双档案遗传搜索—轨迹复盘与对比”四张流程卡，以及当前配置的容量、电压、历史记录数和轨迹数。“数据与验证边界”说明业务数据库只读、候选只引用真实离散记录、严格合格与近可行的用途区别，以及 GA 效果必须通过固定搜索域下的多随机种子实验判断。

## 8. 推荐操作顺序与结论边界

建议按以下顺序使用：

```text
选择三相配置
  → 单设备精算 / 设置本次搜索范围
  → 单设备精算 / 选择一条可还原历史方案并复算
  → 必要时先经 faladi_mcp 触发 Java 最新计算，再到一致性验证页对比
  → GA 优化实验 / 第 0 代准备，检查候选来源与不可计算原因
  → GA 优化实验 / 遗传迭代
  → 轨迹回放，查看代际过程、候选来源和档案结果
```

当前页面和轨迹保存已完成一轮功能测试；单设备 v9 公式也已在 10 条真实记录上完成 320/320 字段回归。配置 401 的 v8 四策略多种子结果只能说明该配置、该搜索域和该预算下的现象，不能证明当前代码已得到全局最优或工程最优结论。本轮新增的运行证据字段、策略下拉、不可计算子代筛除、阻抗无油道邻居回退和负载损耗线规方向尚未经过页面回归；后续执行内容见[后续测试执行清单.md](2026-09-21测试/后续测试执行清单.md)。
