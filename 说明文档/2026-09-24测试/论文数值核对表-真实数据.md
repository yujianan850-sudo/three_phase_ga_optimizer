| 场景 | baseline | coupled | empirical_injection | guided_mutation | mga_single_archive | 可观测到的模块 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| **S-387**（可行率） | 60.0% | 63.3% | 80.0% | **96.7%** | 70.0% | 经验注入 + 诊断反馈 |
| **S-409**（成本） | 100%·25 393 | 100%·25 393 | 100%·**25 181** | 100%·25 181 | 100%·25 181 | 经验注入（成本 + 调用量） |
| **S-469**（双维度） | **40.0%·77 167** | **100%·72 879** | 100%·**72 131** | 100%·72 131 | 100%·72 131 | **耦合交叉 + 经验注入** |
| **S-429**（递增曲线） | 16.7%·10 750 | 20.0%·10 652 | 20.0%·10 750 | 43.3%·10 694 | **63.3%**·11 593 | 诊断反馈 + 单档案（**以成本换可行率**） |
| S-489（不可达） | 0/30 | 0/30 | 0/30 | 0/30 | 0/30 | 仅调用量（8 000 → 1 856） |

**469 是本轮唯一同时分离可行率与成本的场景**：

- `baseline` → `coupled`：可行率 40.0% → 100.0%（**+60 个百分点**），
  成本 77 167.25 → 72 878.50（−5.6%）——**结构电磁耦合交叉唯一一次被观测到明确正面作用**；
- `coupled` → `empirical_injection`：调用量 8 000 → 3 643（−54%），成本再降 1.0%。

**429 是本轮唯一一条完整的递增曲线**（16.7 → 20.0 → 20.0 → 43.3 → 63.3%），
但它的 `mga_single_archive` 成本最差（11 592.75），属**以成本换可行率**，
与 387 的方向相反，**不得**据此声称「双档案有害」。

⇒ 真实数据支持的是「**耦合交叉改善可行率、经验注入改善效率**」，
而不是论文原本的累积故事。

## 4. 本轮真实数据能支持的结论（可直接写进论文）

1. **Java—Python 单设备一致性**：**13 条记录 × 32 字段 = 416 个字段值逐位一致**，
   误差恒为 0；Java 侧取值经 `faladi_mcp` 原始响应核验（B-5 已关闭）。
   **覆盖范围仅限记录 ID ≥ 28927（2026-09-18 20:18 之后）**：
   全库 280 条记录中，其余 267 条因**公式版本**（09-05 前的全分项负载损耗公式）
   或**字段格式**（138 字段 vs 161 字段）不同而**不可用于对照**。
   **主场景的 8 条记录也不在其中**（G9 + B-8）。
2. **搜索效率**：在相同 B′ 与相同第 0 代下，MGA 的演化精算调用量中位数为 BGA 的
   **1/1.85 ~ 1/4.82**（387 3.18×、409 4.82×、469 2.23×、487 1.85×、429 4.15×），
   **5 个场景全部一致**。
3. **成本**：
   - **S-469 显著**：Hodges–Lehmann = **−7.02%**（95% CI [−20.1%, −0.6%]），
     Wilcoxon p = 0.0005，Holm 校正后仍 0.0005；
   - S-409 显著但量级小：−0.83%（95% CI [−2.6%, 0.3%]）；
   - S-487 / S-387 的共同成功配对太少（1 / 14），不足以检验。
4. **严格可行率**：**S-469（BGA 12/30 vs MGA 30/30）与 S-487（1/30 vs 30/30）
   差异极显著**（McNemar 精确检验 p < 0.0001，Holm 后仍 < 0.0001）。
   这是本轮最强的一组结果。
5. **场景可比较性判据**：**只有在「第 0 代无法直接给出严格解」的配置上，
   GA 的演化阶段才有可观测作用**；历史种子已给严格解的配置（143 个中的 9 个）
   会让两法退化为同一答案。5 个主场景的第 0 代命中数**全部为 0**。
6. **首次严格可行精算数**（方案 §6.2 指标）：469 上 BGA 22 396 vs MGA 16 046；
   第 0 代后搜索代价中位 BGA 6 904 vs MGA **554**（**12.5 倍**）。

## 6. 未覆盖边界（论文必须写明）

- **椭圆铁芯**：椭圆 × 波纹（506）/ 椭圆 × 散热器（508）**历史记录已含严格解**，
  用作主场景会让两法退化为同一答案，因此**未纳入主比较**。
- **T1 一致性覆盖范围有限（G9 + 记录 ID 28927 分界）**：
  只有 13 条（416 字段值）可逐位对照，且**全部不属于主比较场景**；
  主比较的 5 个场景（387/409/469/487/429）**没有可用的 Java 侧当前结果**，
  主比较结论只能建立在「Python 精算器已通过 T1 一致性」这一**间接证据**上，
  不能声称「主场景候选的 Java 侧结果已逐条核对」。
- 主比较只覆盖 `Dy` 接线；`Ddyyn11` / `Yy` / `Yd` 共 17 个配置在缺口闭合前不进入结论。
- 未做 RS / MGA-Deb 分层对照（无实现）。
- 可计算率仅 0.1%–1.6%，主场景是**从 143 个配置中筛出的少数可用者**，
  **不能外推为通用性能保证**。
- 「无历史记录」场景（22 个配置）**可计算率为 0**，无法作为场景池（B-7 未解决）。
