### 1.3 🔴 新发现：非最新记录与当前配置快照不一致（影响 T1 口径）

复核配置 497 的 4 条历史记录时发现：

| 记录 ID | 建立时间 | Java `hvrh` | Python 复算 | 差异 |
| --- | --- | ---: | ---: | --- |
| 28917 | 09-16 20:28 | 361.5 | 428.50 | **+67.00** |
| 28919 | 09-17 09:30 | 447.2 | 514.20 | **+67.00** |
| 28921 | 09-17 09:37 | 446.75 | 446.75 | 0 ✅ |
| 28929 | 09-18 20:30 | 446.75 | 446.75 | 0 ✅ |

**根因定位**：配置 497 的 `highVoltageSectionSpacing = 60`，
而 28917/28919 的 `hvrh` 与 **`sectionSpacing = 0`** 的公式结果**逐位吻合**：

```
28917: tps=55, ss=0  -> hvrh = 361.50  ← 与 Java 保存值一致
       tps=55, ss=60 -> hvrh = 428.50  ← Python 当前值
```

⇒ **配置 497 的 `highVoltageSectionSpacing` 在 09-17 09:30 与 09:37 之间被改为 60**，
两条老记录是用**当时的旧配置快照**算出来的。

**影响**：

- 这不是 Python 的公式缺陷，而是**历史记录的配置快照与当前配置不一致**。
- 直接用当前 `scheme_config` 去复算老记录，会得到「对不齐」的假失败——
  上一轮把 497 的 2 条记录计入可计算率分母，**低估了 497 的真实可用性**。
- **T1 采集必须记录每条记录的配置快照时间**，否则「320/320」的结论会被同类问题污染。
  现有 10 条（28927–28939）建立于 09-18 之后，晚于 497 的最后一次配置修改，**未受影响**。

> **本轮新增缺口 G8**：历史记录未固化配置快照 ⇒ 无法判断某条记录是按哪版配置算的。
> 建议 T1 记录选择时**只取配置 `update_time` 之后建立的记录**，并在报告中标注该约束。

而主场景的 8 条记录全部在 **≤ 28927** 的那一侧。

**这构成一条论文必须写明的限制**：

- T1 一致性证据链（320/320）覆盖的是**记录 28697–28939 区间中的新格式记录**，
  其配置（401/415/497/503–508）**不属于主比较场景**；
- 主比较的 5 个场景（387/409/469/487/429）**没有可用的 Java 侧当前结果**，
  因此主比较结论只能建立在「Python 精算器已通过 T1 一致性命中」这一**间接证据**上，
  不能声称「主场景候选的 Java 侧结果已逐条核对」。

> **不得**用主场景的老记录硬凑一致率，也**不得**把 320/320 说成「覆盖了全部主场景」。

### 5.0 🔴 论文表 4 的场景与真实配置完全不对应

把 T0 实际冻结的三个场景与论文表 4 声称的 S1/S2/S3 并排对照
（脚本 `02_场景筛选与预算预试验/compare_paper_scenes.py`）：

| 项 | 论文表 4 声称 | T0 实际冻结 | 是否对应 |
| --- | --- | --- | --- |
| S1 | 100 kVA · 圆形/波纹 · N₀=320 · B′=8 000 | 配置 401：**100 kVA · 长圆/波纹 · N₀=4 444 · B′=5 000** | ❌ 形状不符、N₀ 差 14 倍 |
| S2 | 400 kVA · 长圆/散热器 · N₀=480 · B′=12 000 | 配置 505：**1 500 kVA · 圆形/散热器 · N₀=12 720 · B′=2 500** | ❌ 容量/形状/N₀ 全不符 |
| S3 | 630 kVA · 椭圆/散热器 · N₀=640 · B′=16 000 | 配置 508：**1 500 kVA · 椭圆/散热器 · N₀=12 720 · B′=3 500** | ❌ 容量/N₀ 不符 |

**论文表 4 的 S1/S2/S3 是构造的，与库里任何真实配置都不对应。**
真实第 0 代精算数是 **4 444 / 12 720 / 12 720**，论文写的是 **320 / 480 / 640** ——
差一到两个数量级，直接替换会让论文表 4、表 5（N₀ 与 N 的公式）、表 6—表 9 的全部数字同时失配。

> 另注：配置 401 的容量确实是 100 kVA（与论文 S1 巧合），但铁芯形状是**长圆**不是圆形，
> 且论文给出的 N₀=320 与真实的 4 444 差距过大。这属于巧合，不构成「表 4 有真实依据」。
