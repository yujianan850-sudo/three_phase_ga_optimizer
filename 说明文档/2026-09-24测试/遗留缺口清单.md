## G3 135 条历史记录缺 `lvon`/`hvon` 🟠

### 现象

| 项 | 值 |
| --- | --- |
| 全部记录 | **348** 条 |
| 缺 `lvon` 或 `hvon` | **135** 条 |
| 缺失区间 | 记录 ID **28243 ~ 28525** |
| 完整区间 | 记录 ID **28527 ~ 28939** |
| 分界 | **≤ 28525 缺字段，≥ 28527 有字段**（清晰按 ID 分界） |

### 代码位置

`calculation/record_adapter.py:17`

```python
low_voltage_duct=OilDuctScheme(int(data["lvon"]), int(data["lvot"])),
```

**直接下标取值** ⇒ 字段缺失时抛 `KeyError`，且异常信息只有 `'lvon'` 一个词。

### Java 侧情况

`ThreePhaseSchemeData.java:118` 有 `private Integer LVON;`，
`ThreePhaseSchemeRecordServiceImpl.java:2630` 有 `.setLVON(LVON)`。
⇒ Java 会写该字段，老记录缺字段应是**历史版本未写**。

### 建议方向（未实施）

1. 改为 `.get()` + 显式语义：老记录缺 `lvon`/`hvon` 时按「无油道 `(0,0)`」还是「不可校验」处理，**需先确认**。
2. 或在校验入口按记录 ID 分界，对 ≤28525 的记录明确标注「字段不完整，跳过该字段校验」，**不得静默当作 0**。

## G4 hv 扁线目录缺 4.2 等历史值 🟠

### 现象

记录 28551（配置 293）：`hvwg=3`（扁线）、`hvilw=4.2`、`hvilt=2.45`。
在 `catalog['flat']` 中按 `line_width==4.2 and line_thickness==2.45` 查找 **0 条**；
仅按 `line_width==4.2` 也 **0 条**。

扁线目录 `line_width` 的全部 26 个取值：

```
3.75, 4.00, 4.25, 4.50, 4.75, 5.00, 5.30, 5.60, 6.00, 6.30, 6.70, 7.10,
7.50, 8.00, 8.50, 9.00, 9.50, 10.00, 10.60, 11.20, 11.80, 12.50, 13.20, 14.00, 15.00, 16.00
```

**无 4.2**（最近为 4.25 / 4.00）。

### 代码位置

`calculation/record_adapter.py:_wire_record_id`（`:29-48`）—— `matches` 为空时抛 `LookupError`。

### 判断

这是**目录覆盖问题**（业务侧数据），不是接线问题，也**不应**在 Python 侧做模糊匹配
（会把不同规格当成同一规格，破坏一致性口径）。建议向业务侧确认 4.2 是否为有效历史规格。

## G5 硅钢片磁密损耗数据缺口 🟠

### 现象

369 抽样 200 个候选，其中 **6 条**失败于：

```
铁芯精算首段失败: 硅钢片 27QG110 缺少磁密 3.80 / 3.81 的损耗数据
铁芯精算首段失败: 硅钢片 23ZDK90 缺少磁密 2.99 / 3.00 的损耗数据
铁芯精算首段失败: 硅钢片 27QG110 缺少磁密 2.57 / 2.58 的损耗数据
```

### 代码位置

`calculation/single_device_evaluator.py:_specific_loss`（`:246-254`）：
按 `scale(flux, 2, ROUND_DOWN)` 取相邻两点插值，任一缺失即抛错。

### Java 对照

`ThreePhaseSchemeRecordServiceImpl.java:1240-1244`：

```java
BigDecimal bj5 = CT.setScale(2, RoundingMode.DOWN);
SiliconSteelSheetsConfig config0 = brandConfigs.get(bj5);
if (config0 == null) { continue; }          // ← 缺数据 → 跳过候选
SiliconSteelSheetsConfig config1 = brandConfigs.get(bj5.add(BD_0_01));
if (config1 == null) { continue; }
```

⇒ **Java 在数据缺失时 `continue`（候选不可用）**，Python 抛错。
**与 DEF-2 是同一类语义分歧**，应一并按 `CandidateRejected` 处理（或确认数据表是否应该补齐）。

### 影响面

不止 Ddyyn11 —— `Dy` 侧抽样也出现（近 30 条 Dy 记录中 2 条映射失败，其中含此原因）。
