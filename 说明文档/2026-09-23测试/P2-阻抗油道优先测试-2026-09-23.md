# P2 阻抗油道优先测试（2026-09-23）

## 输入

使用 P1 的配置 445：低压油道允许 `{无油道, 1 个全油道}`，高压油道允许 `{无油道, 1 个全油道, 2 个全油道}`。因此可以验证“只改一侧、只取最近同向档位”，不会被配置 401 的单油道域限制。

证据来自 P1 的 5 条 `guided_mutation` 完整轨迹，以及对同一配置/同一 Python 精算器的上方向邻居复算。

## 实际下方向轨迹

- 共发现 8 条 `primary_violation=impedance` 的诊断探测，全部为 `direction=lower`、`primary_module=radial_duct`。
- 8/8 探测均只改变低压或高压的一侧油道；没有同时改两侧、没有改成非油道模块。
- 8/8 探测后短路阻抗的归一化超限都下降：例如 `0.369624 → 0.344892`、`0.425000 → 0.403226`。
- 这说明在真实运行中，阻抗偏低时算法确实优先尝试“增加一个最近油道档位”，且结果由精算器重新评价，不是根据方向直接假定改善。

## 上方向复算

从同一批真实候选中取一条“阻抗偏高”为主导违规的候选：低压无油道、高压 2 个全油道，UK 为 `7.027%`，归一化超限 `0.673095`。

局部规划仅提出高压 `2 个全油道 → 1 个全油道`；低压保持无油道。用相同 Python 精算器复算后，UK 为 `6.825%`、归一化超限 `0.625000`。没有跳过中间档位直接改为无油道，也没有同时改变低压油道。

## 结论

P2 的核心行为通过：

1. 阻抗主导违规映射到径向油道，而不是铁芯；
2. 偏高时朝较小油道档位、偏低时朝较大油道档位；
3. 每个探测候选只替换一侧的完整油道方案；
4. 每个候选都重新精算，是否改善由结果决定。

边界：本批真实 `guided_mutation` 轨迹自然触发的是“偏低”方向；“偏高”方向用真实历史候选和同一精算器验证了邻居与结果，但不是一次完整 GA 中自然触发的诊断记录。没有同向邻居时回退普通随机变异的分支本轮未单独触发，仍保留为后续回归项；不能将其写成已覆盖。
