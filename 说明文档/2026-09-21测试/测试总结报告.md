layer_insulation = (
    (D("0.26") if bare_t * rpn >= D("1.5") else D("0.21")) if foil
    else (D("0.21") if wire_type <= 1 else D("0.24"))

2. **multiselect 的值连同「会话内切换一级页面」也会重置** ⇒ 设置边界后必须**直接切 GA 页并立即提交**，中途不得返回。
